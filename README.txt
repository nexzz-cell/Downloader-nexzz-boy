VERCEL PROJECT - HTML + JS + JSON

Isi project ini:
- index.html
- script.js
- data.json

Cara deploy:
1. Buka Vercel dan login.
2. Pilih Add New > Project.
3. Import project dari GitHub, atau gunakan opsi upload/deploy folder jika tersedia di dashboard.
4. Framework Preset: Other / static.
5. Build Command: kosongkan.
6. Output Directory: .
7. Deploy.

Catatan: project ini adalah static site. HTML/JS/JSON tidak dapat menyimpan upload file permanen ke server tanpa backend.
